# 300行超ファイルリファクタリング Pilot Plan

目的
- Day8 配下の 300 行以上のモノリス的ファイルを可読性・保守性の観点で単機能ごとに分割するパイロットを実施する。

方針
- HUB.codex.md / TASKS.md の指針に従い、影響範囲と設計案を整理する
- BirdEye の更新方針を定義し、分割後の設計案をサマリ化する

成果物
- 分割設計案のMarkdown、ユニットテスト草案、最小差分実装計画、PR運用ガイド

Pilot Scope
- 対象: Day8 配下の長大ファイル（目安: 300 行以上）の候補を抽出。最初のファイルをパイロットとして単機能化。

具体タスク（初回リリース）
1. 現状把握: 対象ファイル候補のリスト作成
2. 単一責務設計案: 新規モジュール名・エクスポート・APIの最小差分を定義
3. 影響箇所洗い出し: 呼び出し箇所の修正方針
4. パイロット実装: 最初のファイルを分割移動・import/export調整
5. テスト草案: 新モジュールの挙動を検証するユニットテスト案
6. lint/型チェック/テスト: 実行と修正
7. 公開APIの互換性維持: 将来の破壊的変更の段階移行計画を追記
8. ドキュメント化: PRガイド/Seed 追加

次回更新
- 追加分割候補の洗い出し・設計案の更新
- 実装へ移る前の再度の承認プロセス
